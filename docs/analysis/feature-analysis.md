# Feature Analysis

## Overview
Before implementation, I analyzed the business requirements and broke the application into independent features.

## Main Feature
**Security Configurator**

## Builder Steps
1. Select Camera
2. Select Plan
3. Select Sensors
4. Add Extra Protection
5. Checkout

## User Flow
```text
Select Camera
    ↓
Increase Quantity
    ↓
Choose Plan
    ↓
Choose Sensors
    ↓
Add Protection
    ↓
Checkout
```

## Notes
- The application is data-driven.
- Every step updates the review panel.
- Quantities remain synchronized.
- State is shared through a global store.
